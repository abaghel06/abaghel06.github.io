Personal Project

LoanIQ — Intelligent Loan Approval Assistant

Loan decisions aren't just about a credit score — they involve income stability, debt ratios, regulatory compliance, and edge cases that break simple rules. LoanIQ automates that entire evaluation with a pipeline of four specialised AI agents, each responsible for one layer.

An Applicant Profile Agent, Financial Risk Agent, Loan Decision Agent, and Compliance Agent work in sequence — each backed by its own MCP server. The output is a structured decision (Approve / Reject / Manual Review) with a risk score, confidence level, and a compliance case ID.

AWS-Wipro Codeathon

Revenue Leakage Finder

Telecom companies lose money every day to billing gaps they don't even know exist — usage that never got billed, pricing rules applied wrong, payments that failed silently. This project builds an agentic system that hunts those anomalies automatically.

I designed the architecture — an S3-first data lake with EMR/Spark for batch processing, Redshift Serverless for analytics, and Aurora PostgreSQL for transactional data, all provisioned with Terraform — and used Amazon Kiro to guide the build. On top of that sits a multi-agent setup on Bedrock where different agents handle reconciliation, reasoning, and reporting.

Personal Project

Indian CA RAG

Indian tax and compliance questions have real, citable answers buried across the Income Tax Department, ICAI, and GST Council sites — but finding them means digging through PDFs and circulars. This is a RAG API that answers those questions from a knowledge base you control.
